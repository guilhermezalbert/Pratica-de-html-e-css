# Prática HTML e CSS: Portfólio pessoal

**Autor:** Guilherme Alberto Afonso dos Santos

## Descrição
Site de apresentação pessoal com 5 páginas, feito apenas com HTML e CSS para praticar
estrutura semântica, estilização e posicionamento.

## Páginas
- `index.html`: boas-vindas, menu e resumo do site
- `curriculo.html`: formação, experiência, competências e idiomas
- `blog.html`: artigo sobre Flexbox e Grid, com imagem e vídeo
- `fotos.html`: galeria em CSS Grid
- `contato.html`: formulário de contato (sem servidor)

## Paleta de cores (Coolors)
`#14213D` azul-noite · `#FCA311` âmbar · `#E5E5E5` cinza-claro · `#FFFFFF` branco

## Como abrir
Abra o `index.html` no navegador.

## Observações
Os dados de experiência e as imagens são exemplos (placeholders).
